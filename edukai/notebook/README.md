# Notebook

Daily raw capture. One file per day, named `YYYY-MM-DD.md`, created on demand.

- Append freely while working — half-formed observations, pointers, quotes.
- During the session-end heartbeat (see `AGENTS.md`), distill entries into lessons.
- Do not delete distilled lines; annotate them with what they became: `[→ curriculum/<domain>/lessons/<file>]`.
