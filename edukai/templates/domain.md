# New domain checklist

Name: lowercase-hyphen (e.g. `codebase-payments`, `user-armin`, `tooling-rust`).

1. [ ] Create `curriculum/<name>/lessons/`
2. [ ] Copy `templates/overview.md` → `curriculum/<name>/overview.md`, fill in
3. [ ] Register in `SYLLABUS.md` with status `active`
4. [ ] Write the first lesson in the same session — an empty domain is a bug

Retiring a domain: move its folder to `archives/`, set its Syllabus row to `graduated`.
